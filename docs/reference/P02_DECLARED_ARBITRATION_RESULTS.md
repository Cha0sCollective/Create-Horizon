## Source and semantics

Private code commit `3e82f2faf29c5e010d1e0e5b11b7f4c06a0ec053` adds exactly six
files/edits for a closed three-slot event trial, private tests, bridge dispatch,
dedicated comparator and runner mode. Existing solve, geometry, guest, host,
dependencies and Java/reference code are unchanged. The actual run holds the clean
qualified engine at `aa170bc4fd3214790a2363732d0c7cdd57ba6451`.

The model evolves unequal-source merge, dominant removal and subordinate reversal
from absent slots and authored input commands. Parents, network membership, own
generation, driven speed, flicker and deferred activation survive between events.
Capacity sums each motor's OWN generation. Removal follows parent descendants;
subordinate reversal uses the same destruction path. No fixture name selects an
endpoint or outcome. Unsupported topology/configuration/transitions refuse, and
the original general solver retains its multiple-source/cycle/overspeed boundaries.

Native neighbor and BE rounds are declared model ordering. Static bytecode from
exact hash-matched captured dependencies supports the vertical lower-then-upper
neighbor enumeration only; it proves no global Java callback/tick order. The
destruction ledger is domain effects, not native item spawning, movement or recovery.

## Limits

opposite merges, arbitrary graphs/ratios/cycles, source promotion, overspeed,
unloaded contributions, exact Java timing/transient flicker, physical loot/item
conservation, host-world ownership, persistence, external peers and performance
remain unqualified. No engine modification, public publication, merge or release
is implied. S1/G1 and full P02/G2 remain open.
