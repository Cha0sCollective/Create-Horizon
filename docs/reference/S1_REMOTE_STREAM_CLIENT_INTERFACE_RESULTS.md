preparation remains separate from start. Start takes an explicit immutable profile
containing dimension skylight, Nether shading, already-obfuscated biome seed and
client mesh settings. Invalid blend values refuse before acquisition. Profile

a different-profile owner to admit it: refusal returns the original input before
queue, slot or ownership-book changes. Original worker/context/region/receipt
custody and the fixed 64-job policy remain intact.

running/unsealed. Mesh pending reports conservative latest-stamp scheduling state,
not snapshot freshness or completed rendering. Current/stale still comes from the
existing allocation and sequence comparison. Handoff computes that fact before
retiring only its own matching stamp; an older result never clears newer work.

Checked insertion returns the original replaced Arc and preserves the original
incoming Chunk on refusal. Checked forget returns the original resident Arc while
retaining queued/active/stored jobs and their snapshots. Checked light application
validates borrowed protocol layers before mutation and reports Missing, Unchanged
or Replaced. Unchanged preserves the World Arc. Changed light uses detached data,
returns the original Arc, and marks the actual changed neighbor sections using
existing algorithms. Closed, not-running, busy and malformed paths refuse before
World/tracking mutation. No chunk-freeing actor is acquired.

Ordinary/native Streaming construction, worker execution algorithms, native IO,
fatal ownership backstop and all Game factories remain unchanged. This supplies
the interface required for later Game adoption; it does not install that caller.
