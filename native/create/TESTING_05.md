# Визуальная проверка Create 0.5

Откройте instance **Create Processing 0.5**, мир **CreateProcessing05**.
Это отдельный мир; предыдущие миры 0.3/0.4 сохранены. Координаты ниже — позиции
механизмов, посмотреть свои координаты можно через F3. Очки инженера уже надеты,
ключ и основные блоки находятся в инвентаре. Материалы лежат в бочках.
Новые материалы — в бочке `43 64 3`; оставшиеся три предмета каталога —
в бочке `45 64 7`. Старые материалы — в двух бочках возле `27 64 10`.

Проверяйте и любые другие конструкции: стенды — удобные исходные примеры.
Для сообщения об ошибке полезны координаты, входные предметы, RPM и ожидаемый
результат. Особенно полезна конструкция, которая иначе работает в Create 6.0.10.

| Стенд / координаты | Что сделать | Что ожидается |
| --- | --- | --- |
| Пресс, `2 66 2`, депо `2 64 2` | Пустой рукой забрать готовые 8 латунных листов; положить 8 медных слитков. На моторе слева увеличить RPM. | Один слиток за удар; все 8 медных листов можно забрать. После извлечения изображение предмета исчезает. Скорость пресса меняется с RPM. |
| Приборы, `2 66 8` и `3 66 8` | Навести взгляд с надетыми очками; открыть мотор `0 66 8` и изменить 16 → 256 RPM. | HUD показывает сеть, RPM и нагрузку; стрелка скорости меняется. Компаратор за прибором меняет сигнал с 4 на 15. |
| Редуктор, `4 66 8` | Сравнить вращение соединённых половинок валов; добавить выход сбоку. | Соседние соединённые валы согласованы; направление бокового выхода соответствует редуктору. |
| Сцепление, `2 64 14` | Переключить рычаг сверху. | Вход продолжает вращаться; выход сцепления отключается и снова включается. |
| Реверс, `2 64 18` | Переключить рычаг сверху. | Выход меняет направление, вход сохраняет своё. |
| Ручка, `18 66 12` | Вращать ПКМ; затем Shift+ПКМ; попробовать другие грани установки. | Ручка плавно меняет направление, её вал приводит пресс справа. Ручка и основание ориентированы правильно. |
| Вертикальный редуктор, `9 64 12` | Ключом повернуть; поставить ещё один из инвентаря. | Используется тот же блок `create:gearbox` с другой осью; подключаются правильные четыре грани. |
| Передачи шестерён | Соединить большую и маленькую шестерни по диагонали; затем ещё одну пару. | Соотношение 2:1, реверс зацепления, ограничение 256 RPM. Несовместимая замкнутая сеть останавливается. |
| Малое водяное колесо, `13 67 2` | Положить слитки на депо `17 64 3`; заменить магму в канале на песок душ. | Колесо даёт 8 RPM / 256 SU; после передачи пресс получает 16 RPM. Смена течения меняет направление. |
| Большое колесо, `24 67 2` | Нажать досками разных пород; проверить вращение, поставить рядом своё колесо. | 4 RPM / 512 SU, оригинальная геометрия и смена дерева. Крупному колесу нужно место под структурные части. |
| Жернова, `36 65 0` | Положить пшеницу в верхнюю воронку. Забрать результат из сундука `37 64 0`. | Пшеница перерабатывается по одному предмету, мука и вероятностные дополнительные результаты собираются снизу. Алмазы во входной воронке остаются в ней. |
| Жернова вручную | На отдельных жерновах бросить пшеницу сверху, затем нажать пустой рукой. | Предмет захватывается при приземлении. Сначала забираются выходы, затем оставшийся вход. Меню сундука не открывается; вставка ПКМ предметом не заменяет бросание. |
| Промывка, вентилятор `35 65 7`, депо `38 64 7` | Положить муку на депо. | Через воду в ограде мука превращается в тесто. До 16 предметов обрабатываются примерно 7,5 с; 17–32 — примерно 15 с. RPM влияет на дальность, а не время рецепта. |
| Копчение, `35 65 11`, депо `38 64 11` | Положить тесто или сырое мясо. | Поток через зажжённый костёр даёт хлеб или приготовленное мясо. Потушенный костёр рецепты не выполняет. |
| Обработка огнём душ, `35 65 15`, депо `38 64 15` | Положить песок либо булыжник. | Получается песок душ либо чернит. Реверс потока меняет порядок прохождения через разные среды. |
| Обжиг, `35 65 19`, депо `38 64 19` | Положить необработанное железо. | Поток через лаву даёт железные слитки. Еда, которую следовало коптить, при обжиге уничтожается — это поведение оригинала. |
| Воздушный поток | Бросить предмет перед вентилятором; поменять знак RPM, поставить сплошную преграду. | Предмет толкается или притягивается; сплошная преграда ограничивает поток. Депо может стоять на блок ниже воздушного канала. |
| Бур, `45 65 13` | Рычагом на сцеплении `44 66 13` подать вращение. Поставить камень перед головкой, `46 65 13`. | Появляется прогресс разрушения, блок ломается, ресурсы собираются в сундук `47 64 13`. Без вращения прогресс приостанавливается. Бедрок не разрушается. |
| Крафты и предметы | Использовать верстак и материалы; проверить названия и модели в руке/инвентаре, сменить язык при желании. | У реализованных предметов оригинальные ID, переводы и локально импортированные модели/текстуры. Новые механизмы имеют обычные рецепты, а не только командную выдачу. |
| Сохранение | Остановить незавершённую обработку, выйти из мира, открыть снова и включить привод. | Инвентари и поддерживаемые поля прогресса восстанавливаются, лишние предметы не появляются. |

Пшеница даёт вероятностные бонусы муки и семян; их количество не обязано совпадать
между разными запусками миров. Для строгого сравнения количества используйте
детерминированный рецепт жерновов: песчаник → песок.

В этой версии ещё отсутствуют ленты, движущиеся конструкции, поезда, Ponder,
жидкостные машины и полноценные схематики. Воздействие вентилятора на мобов и
игроков и бур на движущихся конструкциях также не реализованы. Форматы и ID
сверяются с Create 6.0.10; перенос полного Java-мира между версиями не обещается.
Проверенные автоматикой сценарии и точные ограничения перечислены в
[VALIDATION.md](VALIDATION.md) и [COMPATIBILITY.md](COMPATIBILITY.md).
